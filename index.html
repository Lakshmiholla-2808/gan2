Open edX Asset Links

Enter up to 5 public Open edX courseware, XBlock, video, text, or other asset URLs. The app attempts to retrieve each URL directly from the browser, extracts accessible page text, and builds an evidence-based audit. Open edX supports public course content and individual XBlock rendering when the installation exposes those pages publicly. citeturn0search2turn0search5

Important: GitHub Pages is a static site. This build does not bypass login, enrollment, CORS, authentication, or private Open edX content. If a URL cannot be fetched from the browser, it is recorded as Needs Verification rather than pretending that the asset was inspected.
Audit principle
Evidence → finding → description → suggestion → severity → fix type → priority. Unsupported claims are flagged for verification rather than invented.
